# Bulk Send (Project B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mail → Send: send a Bulk template (or a one-off message) to active tenants, past tenants, landlords or staff — filtered by location/building or role, with untick/add of individuals — by email and optionally SMS, sent in the background at 25 per minute, with Pause / Resume / Cancel / Resend to failed and every message in the Sent log.

**Architecture:** Two new tables (`bulk_sends`, `bulk_send_recipients`) hold a frozen copy of the texts and the recipient list. `RecipientFinder` turns an audience + filters into people (one per person) with placeholder values; `BulkSendService` validates and creates sends and handles pause/resume/cancel/resend; `BulkSender` (run by the every-minute `bulk-messages:send` command) sends the next 25 pending rows through `SystemMessenger::sendTexts`, respecting a daily limit and a safety stop. `BulkSendController` provides the screens.

**Tech Stack:** Laravel 5.7, PHP (live < 7.4), PostgreSQL, jQuery + TinyMCE (existing), PHPUnit 7.

**Spec:** `docs/superpowers/specs/2026-09-30-bulk-send-design.md`
**Codebase facts (read when a task says so):** `docs/superpowers/plans/bulk-send-facts.md`

- Live PHP is older than 7.4: no arrow functions (`fn`), no typed properties, no `??=`, no nullsafe `?->`, no `match`. PHPUnit 7 style: `protected function setUp()` / `tearDown()` without `: void`.

PHPUnit 7 takes **one** path argument per run.
- Work only in the worktree `C:\laragon\www\plms_b` (branch `feature/bulk-send`). Never touch `C:\laragon\www\plms_master` (it serves the local site); never switch branches; never run composer.
- Tests use the shared local PostgreSQL DB `plms_new` inside `DatabaseTransactions`; no test may send real email or SMS: `Mail::fake()` and `SystemMessenger::$smsSender` stub in every test that can send.
- Known baseline: the full suite has 1 pre-existing failure (`Tests\Feature\ExampleTest::testBasicTest`, GET / → 302). Anything else failing is a regression.
- Nothing existing is removed from master (user rule). Mail → Compose / Inbox (`MassMailController`) stays untouched.
- Permission `bulk_message_send`, granted to roles `super_admin` and `backoffice_manager`.
- Audiences: `tenant_active`, `tenant_past`, `landlord`, `staff`. Past tenant = no contract with `tenant_contract_status` = 1 and newest `tenant_contract_valid_to_date` within the last 12 months.
- Template audience must match: `tenant_active`/`tenant_past` ↔ `tenant`, `landlord` ↔ `landlord`, `staff` ↔ `staff`; a template with audience `any` fits all.
- SMS is a per-send choice, **off by default**; SMS needs SMS text. Email needs subject and body.
- Rate: settings `bulk_emails_per_minute` = `25`, `bulk_emails_per_day` = `8000` (configuration rows, `configuration_name` = `settings`). Missing row → use 25 / 8000.
- Daily limit counts only bulk emails (`message_log.related_type` = `bulk_send`, channel `email`, status `sent`/`failed`) since midnight; system emails are not counted.
- Safety stop: 5 consecutive email failures in one send → send `paused`, note `Paused: mail server refusing`.
- Daily-limit note text exactly: `Daily limit reached, continues tomorrow`.
- `message_log` rows of bulk sends: `template_key` = `bulk:<template_id>` or `bulk:one-off`, `related_type` = `bulk_send`, `related_id` = send id.
- Frozen at Start: texts and the recipient list (with values). Template edits later do not change a send.
- Code style: follow neighbouring files (CRLF line endings in existing files), module namespaces `Modules\BackOffice\...`, views `backoffice::BulkSend.*` extending `layouts.plms-app`.
- Commit messages end with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- **Same person reached through several contracts / roles** — a tenant with contracts on several units, a staff user with several roles: expected exactly one message. → Task 3 tests.
- **Template audience mismatch** (a Tenants template picked for Staff) and **SMS ticked with no SMS text**: expected a clear validation message, nothing created. → Task 4 tests.
- **Daily limit hit mid-send, then a new day**: expected the send waits with the note, system emails unaffected, and it continues after midnight. → Task 5 tests.
- **Pause / Cancel while rows are pending**: expected no further messages for that send; Cancel marks all pending rows `cancelled`. → Task 5 tests.
- **Page-level permission**: a user without `bulk_message_send` must get 403 on every Send route (list, create, review, store, actions). → Task 6 / Task 7 tests.

```php
<?php

namespace Modules\BackOffice\Entities;

use Illuminate\Database\Eloquent\Model;

/** A bulk send (Mail -> Send). Texts are a frozen copy taken when the send started. */
class BulkSend extends Model
{
    const RUNNING = 'running';
    const PAUSED = 'paused';
    const CANCELLED = 'cancelled';
    const DONE = 'done';

    const NOTE_DAILY_LIMIT = 'Daily limit reached, continues tomorrow';
    const NOTE_SAFETY_STOP = 'Paused: mail server refusing';

    const AUDIENCE_LABELS = [
        'tenant_active' => 'Active tenants',
        'tenant_past'   => 'Past tenants (ended in the last 12 months)',
        'landlord'      => 'Landlords',
        'staff'         => 'Staff',
    ];

    protected $table = 'bulk_sends';
    protected $guarded = [];
    protected $casts = ['filters' => 'array', 'send_email' => 'boolean', 'send_sms' => 'boolean'];
    protected $dates = ['finished_at'];

    public function recipients()
    {
        return $this->hasMany(BulkSendRecipient::class, 'bulk_send_id');
    }

    public function template()
    {
        return $this->belongsTo(MessageTemplate::class, 'template_id')->withTrashed();
    }

    public function creator()
    {
        return $this->belongsTo('App\User', 'created_by');
    }

    /** message_log.template_key for this send's messages. */
    public function logKey()
    {
        return 'bulk:' . ($this->template_id ? $this->template_id : 'one-off');
    }

    public function texts()
    {
        return ['email_subject' => $this->email_subject, 'email_body' => $this->email_body, 'sms_body' => $this->sms_body];
    }

    public function pendingCount()
    {
        return $this->recipients()->where('status', BulkSendRecipient::PENDING)->count();
    }
}
```

**Interfaces:**
- Consumes: `StaffMessages::userRecipients($users)` → `[[User, MessageRecipient], ...]`; `MessageValues::employee($user)`; `MessageValues::contract($contract)` (for the consistency test only).
- Produces:
  - `RecipientFinder::people($audience, array $filters)` → array keyed `"<type>:<id>"` (`tenant:12`, `landlord:5`, `staff:3`) of `['person_type' => string, 'person_id' => int, 'name' => string, 'email' => ?string, 'mobile' => ?string, 'values' => array]`. Throws `\InvalidArgumentException` for an unknown audience.
  - `RecipientFinder::count($audience, array $filters)` → `['total' => int, 'email' => int, 'mobile' => int]`.
  - `RecipientFinder::person($audience, $key)` → one person (no filters) or null.
  - `RecipientFinder::search($audience, $term, $limit = 20)` → list of `['key', 'name', 'email', 'mobile']` whose name contains the term (case-insensitive), no filters.
  - `RecipientFinder::templateAudience($audience)` → `'tenant'|'landlord'|'staff'`.
  - `RecipientFinder::buildingIds(array $filters)` → `null` (no filter) or list of building ids (`[]` = filter matched nothing).
  - `$filters` keys: `locations` (location ids), `buildings` (building ids), `roles` (role names). Buildings win over locations when both are given.
- Rules (spec): active tenant = `tenant.tenant_status` = 1 with a `tenant_contracts.tenant_contract_status` = 1 contract (in the filtered buildings when filtered); values from the newest such contract (by `tenant_contract_effective_date` desc, id desc). Past tenant = no status-1 contract at all, max `tenant_contract_valid_to_date` ≥ today − 12 months; with a building filter, needs a contract in those buildings; values from the newest contract in the pool. <?php

```php
namespace Modules\BackOffice\Services\Bulk;

use App\User;
use Illuminate\Support\Facades\DB;
use Modules\BackOffice\Services\MessageValues;
use Modules\BackOffice\Services\StaffMessages;

/**
 * Bulk send recipients: an audience (tenant_active, tenant_past, landlord,
 * staff) plus filters (locations, buildings, roles) -> one row per person
 * with the placeholder values for their message. The review screen and the
 * start of a send use the same code, so counts match what is sent.
 */
class RecipientFinder
{
    public static function templateAudience($audience)
    {
        if ($audience === 'landlord' || $audience === 'staff') {
            return $audience;
        }
        return 'tenant';
    }

    public static function people($audience, array $filters)
    {
        switch ($audience) {
            case 'tenant_active':
                return self::tenants(true, $filters);
            case 'tenant_past':
                return self::tenants(false, $filters);
            case 'landlord':
                return self::landlords($filters);
            case 'staff':
                return self::staff($filters);
        }
        throw new \InvalidArgumentException('Unknown audience: ' . $audience);
    }

    public static function count($audience, array $filters)
    {
        $email = 0;
        $mobile = 0;
        $people = self::people($audience, $filters);
        foreach ($people as $p) {
            if ($p['email']) { $email++; }
            if ($p['mobile']) { $mobile++; }
        }
        return ['total' => count($people), 'email' => $email, 'mobile' => $mobile];
    }

    public static function person($audience, $key)
    {
        $all = self::people($audience, []);
        return isset($all[$key]) ? $all[$key] : null;
    }

    public static function search($audience, $term, $limit = 20)
    {
        $term = mb_strtolower(trim((string) $term), 'UTF-8');
        if ($term === '') {
            return [];
        }
        $out = [];
        foreach (self::people($audience, []) as $key => $p) {
            if (mb_strpos(mb_strtolower($p['name'], 'UTF-8'), $term, 0, 'UTF-8') !== false) {
                $out[] = ['key' => $key, 'name' => $p['name'], 'email' => $p['email'], 'mobile' => $p['mobile']];
                if (count($out) >= $limit) {
                    break;
                }
            }
        }
        return $out;
    }

    /** null = no building filter; [] = the filter matches no building. */
    public static function buildingIds(array $filters)
    {
        $buildings = self::ints(isset($filters['buildings']) ? $filters['buildings'] : []);
        if ($buildings) {
            return $buildings;
        }
        $locations = self::ints(isset($filters['locations']) ? $filters['locations'] : []);
        if ($locations) {
            return self::ints(DB::table('buildings')->whereIn('location_id', $locations)->pluck('id')->all());
        }
        return null;
    }

    private static function ints($list)
    {
        $out = [];
        foreach ((array) $list as $v) {
            if ((int) $v > 0) {
                $out[] = (int) $v;
            }
        }
        return array_values(array_unique($out));
    }

    private static function row($type, $id, $name, $email, $mobile, array $values)
    {
        $email = trim((string) $email);
        $mobile = trim((string) $mobile);
        return [
            'person_type' => $type, 'person_id' => (int) $id, 'name' => trim((string) $name),
            'email' => $email !== '' ? $email : null, 'mobile' => $mobile !== '' ? $mobile : null, 'values' => $values,
        ];
    }

    private static function dash($v)
    {
        $v = trim((string) $v);
        return $v === '' ? '-' : $v;
    }

    private static function date($v)
    {
        return $v ? date('d/m/Y', strtotime($v)) : '-';
    }

    /** Same keys and formats as MessageValues::contract(). */
    public static function tenantValues($r)
    {
        return [
            'tenant_name'    => self::dash($r->tenant_name),
            'contract_no'    => self::dash($r->tenant_contract_no),
            'building'       => self::dash($r->building_name),
            'unit'           => self::dash($r->unit_no),
            'location'       => self::dash($r->locations_name),
            'rent'           => ($r->tenant_contract_rent !== null && $r->tenant_contract_rent !== '') ? number_format((float) $r->tenant_contract_rent, 3) : '-',
            'contract_start' => self::date($r->tenant_contract_start_date),
            'contract_end'   => self::date($r->tenant_contract_valid_to_date),
            'mobile'         => self::dash($r->tenant_contact_no ? $r->tenant_contact_no : $r->tenant_residence_tel),
        ];
    }

    private static function tenants($active, array $filters)
    {
        $buildingIds = self::buildingIds($filters);
        if ($buildingIds === []) {
            return [];
        }
        $rows = DB::table('tenant_contracts as c')
            ->join('tenant as t', 't.id', '=', 'c.tenant_id')
            ->leftJoin('buildings as b', 'b.id', '=', 'c.building_id')
            ->leftJoin('locations as l', 'l.id', '=', 'b.location_id')
            ->leftJoin('units as u', 'u.id', '=', 'c.unit_id')
            ->select('t.id as tenant_id', 't.tenant_name', 't.tenant_status', 't.tenant_contact_email', 't.tenant_personal_email',
                     't.tenant_contact_no', 't.tenant_residence_tel', 'c.id as contract_id', 'c.building_id', 'c.tenant_contract_no',
                     'c.tenant_contract_status', 'c.tenant_contract_rent', 'c.tenant_contract_start_date',
                     'c.tenant_contract_effective_date', 'c.tenant_contract_valid_to_date', 'b.building_name', 'l.locations_name', 'u.unit_no')
            ->orderBy('c.tenant_contract_effective_date', 'desc')->orderBy('c.id', 'desc')
            ->get();

        $byTenant = [];
        foreach ($rows as $r) {
            $byTenant[$r->tenant_id][] = $r;
        }
        $cutoff = date('Y-m-d', strtotime('-12 months'));
        $out = [];
        foreach ($byTenant as $tenantId => $contracts) {
            $activeOnes = [];
            $lastEnd = '';
            foreach ($contracts as $c) {
                if ((int) $c->tenant_contract_status === 1) {
                    $activeOnes[] = $c;
                }
                $end = substr((string) $c->tenant_contract_valid_to_date, 0, 10);
                if ($end > $lastEnd) {
                    $lastEnd = $end;
                }
            }
            if ($active) {
                if ((int) $contracts[0]->tenant_status !== 1 || !$activeOnes) {
                    continue;
                }
                $pool = $activeOnes;
            } else {
                if ($activeOnes || $lastEnd === '' || $lastEnd < $cutoff) {
                    continue;
                }
                $pool = $contracts;
            }
            if ($buildingIds !== null) {
                $pool = array_values(array_filter($pool, function ($c) use ($buildingIds) {
                    return in_array((int) $c->building_id, $buildingIds, true);
                }));
                if (!$pool) {
                    continue;
                }
            }
            $c = $pool[0];
            $email = $c->tenant_contact_email ? $c->tenant_contact_email : $c->tenant_personal_email;
            $mobile = $c->tenant_contact_no ? $c->tenant_contact_no : $c->tenant_residence_tel;
            $out['tenant:' . $tenantId] = self::row('tenant', $tenantId, $c->tenant_name, $email, $mobile, self::tenantValues($c));
        }
        return $out;
    }

    private static function landlords(array $filters)
    {
        $buildingIds = self::buildingIds($filters);
        if ($buildingIds === []) {
            return [];
        }
        $contracts = DB::table('landlord_contract as lc')
            ->join('buildings as b', 'b.id', '=', 'lc.building_id')
            ->leftJoin('locations as l', 'l.id', '=', 'b.location_id')
            ->where('lc.landlord_contract_status', 1)
            ->orderBy('lc.landlord_contract_valid_to_date', 'desc')->orderBy('lc.id', 'desc')
            ->get(['lc.vendor_id', 'lc.building_id', 'b.building_name', 'l.locations_name']);
        $byVendor = [];
        foreach ($contracts as $c) {
            $byVendor[$c->vendor_id][] = $c;
        }
        $vendors = DB::table('vendors')->where('vendor_type_id', 2)->where('vendor_status', 1)->orderBy('vendor_name')
            ->get(['id', 'vendor_name', 'vendor_contact_email', 'vendor_contact_no']);
        $out = [];
        foreach ($vendors as $v) {
            $pool = isset($byVendor[$v->id]) ? $byVendor[$v->id] : [];
            if ($buildingIds !== null) {
                $pool = array_values(array_filter($pool, function ($c) use ($buildingIds) {
                    return in_array((int) $c->building_id, $buildingIds, true);
                }));
                if (!$pool) {
                    continue;
                }
            }
            $c = $pool ? $pool[0] : null;
            $out['landlord:' . $v->id] = self::row('landlord', $v->id, $v->vendor_name, $v->vendor_contact_email, $v->vendor_contact_no, [
                'landlord_name' => self::dash($v->vendor_name),
                'building'      => $c ? self::dash($c->building_name) : '-',
                'location'      => $c ? self::dash($c->locations_name) : '-',
            ]);
        }
        return $out;
    }

    private static function staff(array $filters)
    {
        $roles = array_values(array_filter(isset($filters['roles']) ? (array) $filters['roles'] : []));
        $q = User::active()->orderBy('id');
        if ($roles) {
            $ids = DB::table('model_has_roles')->join('roles', 'roles.id', '=', 'model_has_roles.role_id')
                ->whereIn('roles.name', $roles)->where('model_has_roles.model_type', 'App\User')->pluck('model_has_roles.model_id');
            $q->whereIn('id', $ids);
        }
        $out = [];
        foreach (StaffMessages::userRecipients($q->get()) as $pair) {
            $user = $pair[0];
            $to = $pair[1];
            $out['staff:' . $user->id] = self::row('staff', $user->id, $to->name, $to->email, $to->mobile, MessageValues::employee($user));
        }
        return $out;
    }
}
```

```php
            self::fail('audience', 'Choose who to send to.');

            self::fail('sms_body', 'This message has no SMS text.');

    {
        $texts = self::checkMessage($in);
        $audience = (string) $in['audience'];
        $email = !empty($in['send_email']);
        $sms = !empty($in['send_sms']);

        $filters = isset($in['filters']) ? (array) $in['filters'] : [];
        $people = RecipientFinder::people($audience, $filters);
        foreach (isset($in['exclude']) ? (array) $in['exclude'] : [] as $key) {
            unset($people[$key]);
        }
        foreach (isset($in['add']) ? (array) $in['add'] : [] as $key) {
            if (!isset($people[$key])) {
                $p = RecipientFinder::person($audience, $key);
                if ($p) {
                    $people[$key] = $p;
                }
            }
        }
        if (!$people) {
            self::fail('recipients', 'Nobody to send to.');
        }

        return DB::transaction(function () use ($texts, $audience, $filters, $email, $sms, $people, $userId) {
            $send = BulkSend::create($texts + [

                'status' => BulkSend::RUNNING, 'total' => count($people), 'created_by' => $userId,
            ]);
            self::insertRecipients($send, array_values($people));
            return $send;
        });

    {
        foreach (array_chunk($people, 500) as $chunk) {
            $rows = [];

                $rows[] = [
                    'bulk_send_id' => $send->id, 'person_type' => $p['person_type'], 'person_id' => $p['person_id'],
                    'name' => mb_substr((string) $p['name'], 0, 150, 'UTF-8'), 'email' => $p['email'] !== null ? mb_substr($p['email'], 0, 190, 'UTF-8') : null,
                    'mobile' => $p['mobile'] !== null ? mb_substr($p['mobile'], 0, 30, 'UTF-8') : null,
                    'values' => json_encode($p['values']), 'status' => BulkSendRecipient::PENDING,
                ];
            }
            DB::table('bulk_send_recipients')->insert($rows);
        }
    }

    public static function pause(BulkSend $send)
    {
        if ($send->status === BulkSend::RUNNING) {
            $send->update(['status' => BulkSend::PAUSED]);
        }
    }

    public static function resume(BulkSend $send)
    {
        if ($send->status === BulkSend::PAUSED) {
            $send->update(['status' => BulkSend::RUNNING, 'note' => null, 'email_fail_streak' => 0]);
        }
    }

    public static function cancel(BulkSend $send)
    {
        if (in_array($send->status, [BulkSend::RUNNING, BulkSend::PAUSED], true)) {
            DB::transaction(function () use ($send) {
                $send->recipients()->where('status', BulkSendRecipient::PENDING)
                    ->update(['status' => BulkSendRecipient::CANCELLED, 'processed_at' => now()]);
                $send->update(['status' => BulkSend::CANCELLED, 'finished_at' => now()]);
            });
        }
    }

    public static function resendFailed(BulkSend $send, $userId)
    {

                'send_email' => $send->send_email, 'send_sms' => $send->send_sms,
                'status' => BulkSend::RUNNING, 'total' => $failed->count(), 'created_by' => $userId,
            ]);
            $people = [];
            foreach ($failed as $r) {
                $people[] = ['person_type' => $r->person_type, 'person_id' => $r->person_id, 'name' => $r->name,
                             'email' => $r->email, 'mobile' => $r->mobile, 'values' => $r->values ? $r->values : []];
            }
            self::insertRecipients($new, $people);
            return $new;
        });
    }
```

```php
namespace Modules\BackOffice\Services\Bulk;

use Modules\BackOffice\Entities\BulkSend;
use Modules\BackOffice\Entities\BulkSendRecipient;
use Modules\BackOffice\Entities\MessageLog;
use Modules\BackOffice\Services\MessageRecipient;
use Modules\BackOffice\Services\SystemMessenger;

/**
 * Runs every minute (bulk-messages:send): sends the next pending recipients of
 * running bulk sends at the configured rate, below Office 365's limits.
 */
class BulkSender
{
    const SAFETY_STOP_AFTER = 5;

    private static function setting($key, $default)
    {
        $row = prefixData($key);
        $v = $row ? (int) $row->configuration_value : 0;
        return $v > 0 ? $v : $default;
    }

    public static function emailsToday()
    {
        return MessageLog::where('related_type', 'bulk_send')->where('channel', 'email')
            ->whereIn('status', [MessageLog::SENT, MessageLog::FAILED])
            ->where('created_at', '>=', now()->startOfDay())->count();
    }

    public static function run()
    {
        $summary = ['processed' => 0, 'sent' => 0, 'failed' => 0, 'skipped' => 0];
        $perMinute = self::setting('bulk_emails_per_minute', 25);
        $perDay = self::setting('bulk_emails_per_day', 8000);
        $today = self::emailsToday();

        if ($today >= $perDay) {
            BulkSend::where('status', BulkSend::RUNNING)->update(['note' => BulkSend::NOTE_DAILY_LIMIT]);
            return $summary;
        }
        BulkSend::where('status', BulkSend::RUNNING)->where('note', BulkSend::NOTE_DAILY_LIMIT)->update(['note' => null]);

        $limit = min($perMinute, $perDay - $today);
        $rows = BulkSendRecipient::where('status', BulkSendRecipient::PENDING)
            ->whereIn('bulk_send_id', BulkSend::where('status', BulkSend::RUNNING)->pluck('id'))
            ->orderBy('bulk_send_id')->orderBy('id')->limit($limit)->get();

        $sends = [];
        foreach ($rows as $row) {
            if (!isset($sends[$row->bulk_send_id])) {
                $sends[$row->bulk_send_id] = BulkSend::find($row->bulk_send_id);
            }
            $send = $sends[$row->bulk_send_id];
            if ($send->fresh()->status !== BulkSend::RUNNING) {
                continue;
            }
            $status = self::sendOne($send, $row);
            $summary['processed']++;
            $summary[$status]++;
        }

        foreach (BulkSend::where('status', BulkSend::RUNNING)->get() as $send) {
            if ($send->pendingCount() === 0) {
                $send->update(['status' => BulkSend::DONE, 'finished_at' => now()]);
            }
        }
        return $summary;
    }

    /** @return string sent|failed|skipped */
    private static function sendOne(BulkSend $send, BulkSendRecipient $row)
    {
        $result = SystemMessenger::sendTexts(
            $send->logKey(), $send->texts(),
            new MessageRecipient($row->name, $row->email, $row->mobile),
            $row->values ? $row->values : [],
            ['related' => ['bulk_send', $send->id], 'channels' => ['email' => $send->send_email, 'sms' => $send->send_sms]]
        );

        $parts = [];
        $statuses = [];
        foreach (['email', 'sms'] as $ch) {
            if ($result[$ch] !== null) {
                $parts[] = $ch . ': ' . $result[$ch];
                $statuses[] = $result[$ch];
            }
        }
        if (in_array(MessageLog::SENT, $statuses, true)) {
            $status = BulkSendRecipient::SENT;
        } elseif (in_array(MessageLog::FAILED, $statuses, true)) {
            $status = BulkSendRecipient::FAILED;
        } else {
            $status = BulkSendRecipient::SKIPPED;
        }
        $row->update(['status' => $status, 'note' => mb_substr(implode('; ', $parts), 0, 255, 'UTF-8'), 'processed_at' => now()]);
        $send->increment($status);

        if ($result['email'] === MessageLog::FAILED) {
            $send->increment('email_fail_streak');
            if ((int) $send->fresh()->email_fail_streak >= self::SAFETY_STOP_AFTER) {
                $send->update(['status' => BulkSend::PAUSED, 'note' => BulkSend::NOTE_SAFETY_STOP]);
            }
        } elseif ($result['email'] === MessageLog::SENT && (int) $send->email_fail_streak !== 0) {
            $send->update(['email_fail_streak' => 0]);
        }
        return $status;
    }
}
```

```php
<?php

namespace Modules\BackOffice\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Routing\Controller;
use Illuminate\Validation\ValidationException;
use Modules\BackOffice\Entities\BulkSend;
use Modules\BackOffice\Entities\BulkSendRecipient;
use Modules\BackOffice\Services\Bulk\BulkSendService;

/** Mail -> Send: bulk messages to tenants, landlords or staff. */
class BulkSendController extends Controller
{
    const PER_PAGE = 50;

    public function __construct()
    {
        $this->middleware('auth');
        $this->middleware('permission:bulk_message_send');
    }

    public function index()
    {
        $sends = BulkSend::with(['template', 'creator'])->orderBy('id', 'desc')->paginate(self::PER_PAGE);
        return view('backoffice::BulkSend.index', compact('sends'));
    }

    public function show(Request $request, BulkSend $bulkSend)
    {
        $status = $request->input('status');
        $q = $bulkSend->recipients()->orderBy('id');
        if ($status && in_array($status, ['pending', 'sent', 'failed', 'skipped', 'cancelled'], true)) {
            $q->where('status', $status);
        }
        $recipients = $q->paginate(self::PER_PAGE)->appends(['status' => $status]);
        return view('backoffice::BulkSend.show', ['send' => $bulkSend, 'recipients' => $recipients, 'status' => $status]);
    }

    public function pause(BulkSend $bulkSend)
    {
        BulkSendService::pause($bulkSend);
        return redirect()->route('bulk-send.index')->with('success', 'Send #' . $bulkSend->id . ' paused');
    }

    public function resume(BulkSend $bulkSend)
    {
        BulkSendService::resume($bulkSend);
        return redirect()->route('bulk-send.index')->with('success', 'Send #' . $bulkSend->id . ' resumed');
    }

    public function cancel(BulkSend $bulkSend)
    {
        BulkSendService::cancel($bulkSend);
        return redirect()->route('bulk-send.index')->with('success', 'Send #' . $bulkSend->id . ' cancelled');
    }

    public function resendFailed(BulkSend $bulkSend)
    {
        try {
            $new = BulkSendService::resendFailed($bulkSend, \Auth::id());
        } catch (ValidationException $e) {
            return redirect()->route('bulk-send.index')->with('error', collect($e->errors())->flatten()->first());
        }
        return redirect()->route('bulk-send.index')->with('success', 'Send #' . $new->id . ' started for ' . $new->total . ' failed message(s)');
    }
}
```

```php
    /** Request -> the input BulkSendService expects. */
    private function input(Request $request)
    {
        $audience = (string) $request->input('audience');
        $filters = [];
        if ($audience === 'staff') {
            $filters['roles'] = array_values(array_filter((array) $request->input('roles', [])));
        } else {
            $filters['locations'] = array_values(array_filter((array) $request->input('locations', [])));
            $filters['buildings'] = array_values(array_filter((array) $request->input('buildings', [])));
        }
        return [
            'template_id'   => $request->input('template_id') ? (int) $request->input('template_id') : null,
            'email_subject' => $request->input('email_subject'),
            'email_body'    => $request->input('email_body'),
            'sms_body'      => $request->input('sms_body'),
            'audience'      => $audience,
            'filters'       => $filters,
            'send_email'    => (bool) $request->input('send_email'),
            'send_sms'      => (bool) $request->input('send_sms'),
            'exclude'       => array_values((array) $request->input('exclude', [])),
            'add'           => array_values((array) $request->input('add', [])),
        ];
    }

    public function create()
    {
        $templates = MessageTemplate::where('kind', MessageTemplate::KIND_BULK)->where('is_active', true)->orderBy('name')
            ->get(['id', 'name', 'audience', 'email_subject', 'email_body', 'sms_body']);
        $locations = DB::table('locations')->where('locations_status', 1)->orderBy('locations_name')->get(['id', 'locations_name']);
        $buildings = DB::table('buildings')->where('building_status', 1)->orderBy('building_name')->get(['id', 'building_name', 'location_id']);
        $roles = DB::table('roles')->orderBy('name')->pluck('name');
        $placeholders = [];
        foreach (array_keys(MessagePlaceholders::AUDIENCES) as $a) {
            $placeholders[$a] = MessagePlaceholders::forTemplate($a);
        }
        return view('backoffice::BulkSend.create', compact('templates', 'locations', 'buildings', 'roles', 'placeholders'));
    }

    public function count(Request $request)
    {
        $in = $this->input($request);
        if (!isset(BulkSend::AUDIENCE_LABELS[$in['audience']])) {
            return response()->json(['total' => 0, 'email' => 0, 'mobile' => 0]);
        }
        return response()->json(RecipientFinder::count($in['audience'], $in['filters']));
    }

    public function review(Request $request)
    {
        $in = $this->input($request);
        try {
            $texts = BulkSendService::checkMessage($in);
        } catch (ValidationException $e) {
            return redirect()->route('bulk-send.create')->withErrors($e->errors())->withInput();
        }
        $people = RecipientFinder::people($in['audience'], $in['filters']);
        $list = [];
        foreach ($people as $key => $p) {
            $list[] = ['key' => $key, 'name' => $p['name'], 'email' => $p['email'], 'mobile' => $p['mobile']];
        }
        $perMinute = (int) (prefixData('bulk_emails_per_minute') ? prefixData('bulk_emails_per_minute')->configuration_value : 25);
        $perMinute = $perMinute > 0 ? $perMinute : 25;
        return view('backoffice::BulkSend.review', [
            'in' => $in, 'texts' => $texts, 'list' => $list, 'perMinute' => $perMinute,
            'audienceLabel' => BulkSend::AUDIENCE_LABELS[$in['audience']],
            'template' => $texts['template_id'] ? MessageTemplate::find($texts['template_id']) : null,
        ]);
    }

    public function search(Request $request)
    {
        $audience = (string) $request->input('audience');
        if (!isset(BulkSend::AUDIENCE_LABELS[$audience])) {
            return response()->json([]);
        }
        return response()->json(RecipientFinder::search($audience, $request->input('q')));
    }

    public function preview(Request $request)
    {
        $in = $this->input($request);
        if (!isset(BulkSend::AUDIENCE_LABELS[$in['audience']])) {
            return response()->json(['subject' => null, 'html' => null, 'sms' => null]);
        }
        try {
            $texts = BulkSendService::texts($in, $in['audience']);
        } catch (ValidationException $e) {
            return response()->json(['error' => collect($e->errors())->flatten()->first()], 422);
        }
        $person = RecipientFinder::person($in['audience'], (string) $request->input('key'));
        $values = ($person ? $person['values'] : []) + ['today' => date('d/m/Y'), 'company_name' => 'Al Habib & Co. L.L.C'];
        $out = MessageTemplateRenderer::render($texts, $values);
        return response()->json(['subject' => $out['subject'], 'html' => $out['html'], 'sms' => $out['sms']]);
    }

    public function store(Request $request)
    {
        try {
            $send = BulkSendService::start($this->input($request), \Auth::id());
        } catch (ValidationException $e) {
            return redirect()->route('bulk-send.create')->withErrors($e->errors())->withInput();
        }
        return redirect()->route('bulk-send.index')->with('success', 'Send #' . $send->id . ' started: ' . $send->total . ' people.');
    }
```

```blade
(function () {
```
